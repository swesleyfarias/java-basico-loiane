# Java Exercises - Loiane Groner Course

Repository dedicated to Java exercises from Loiane Groner's free Java course.

The main goal of this repository is to build a strong foundation in:

- Programming logic
- Object-Oriented Programming (OOP)
- Java fundamentals

## My Journey

Before starting this repository, I completed Gustavo Guanabara's Algorithms course, where I learned programming logic using Portugol.

To reinforce my learning, I decided to solve the exercises again in Java on my own. This process has helped me strengthen my logical thinking and gain a deeper understanding of Java fundamentals.

Since reaching the OOP section, I have been organizing classes, methods, and projects using English naming conventions to gradually improve both my programming skills and technical English.

## Repository Structure

The repository is organized by topic, and each OOP exercise is separated into its own package containing the implementation class and a corresponding test class.
